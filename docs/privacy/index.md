# Cloud Mounter Privacy Policy

Effective date: October 4, 2026

Cloud Mounter is a desktop applet that helps users configure and control cloud
and network storage connections on their own computers.

## Google user data

When a user authorizes a Google Drive connection, the locally installed rclone
engine requests access to the Google Drive files and folders selected by the
user. This access is used only to provide the mount or synchronization operation
requested by the user.

Google OAuth tokens and provider credentials are retained locally by the
connection engine. Cloud Mounter does not send Google user data, OAuth tokens,
or provider credentials to the Cloud Mounter developer or to a Cloud Mounter
server. Cloud Mounter does not operate a server that receives this information.

## Local information

Cloud Mounter stores connection settings needed to operate the applet, such as
connection names, local paths, selected providers, remote names, and mount or
synchronization preferences. Connection engines may separately maintain local
credentials, tokens, caches, synchronized files, and logs according to their
own configuration and policies.

Cloud Mounter does not include advertising or analytics and does not sell user
information.

## Sharing and disclosure

Cloud Mounter does not share Google user data with the developer or other third
parties. The selected connection engine communicates with Google and performs
the storage operation requested by the user. Users should also review the
privacy and security documentation for the connection engine they choose.

## Retention and deletion

Cloud Mounter's applet settings remain on the user's computer until the user
removes them. Provider credentials, tokens, caches, mirrored files, and engine
configuration remain under the control of the respective connection engine and
may need to be removed separately. A user can revoke Google access at any time
from the security settings of their Google Account.

## Security

Cloud Mounter relies on the operating system, Google OAuth, and the selected
connection engine to protect locally stored credentials and data. Users are
responsible for maintaining the security of their computer and account.

## Changes to this policy

This policy may be updated when Cloud Mounter's functionality or data practices
change. The effective date above identifies the current version.
