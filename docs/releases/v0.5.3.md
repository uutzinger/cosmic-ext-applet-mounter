# Cloud Mounter 0.5.3

Status: Native release notes prepared — not published; hosted package gate pending.

Scope: Native source installation and Debian packages. Final Flatpak delivery is
deferred to 0.5.4; current three-engine behavior is retained for this release.

## Changes

- Typed NetworkManager and systemd D-Bus control replaces desktop CLI wrappers.
- A shared Rust coordinator manages guarded rclone offline synchronization,
  scheduling, cancellation, repair, and retention cleanup.
- Online and offline recovery reconcile the UI with observed backend state.
- Panel opening uses asynchronous cached service observations instead of blocking
  status queries.
- OpenConnect VPN authentication uses the documented host authentication-agent
  setup; other NetworkManager VPNs do not require that OpenConnect-specific agent.
- Optional OneDrive authentication-helper runtime dependencies are declared.
- Native OneDrive Offline setup retains interactive authentication and the
  optional graphical WebKit helper for Manual Auth Handoff; no forced browser-
  history/copy-paste default is introduced for source/Debian installations.

## Installation and compatibility

Hosts lacking Documents portal v5 retain the documented, capability-gated
`flatpak document-info` fallback. Engine execution and narrowly scoped host
inspection exceptions remain; see the
[host-command inventory](../engineering/flatpak-host-command-inventory.md).
